# Production Flow

Англоязычное интерактивное демо учёта производственных задач. Данные вымышленные.

## Запуск

Требуется Node.js 22.18+ в ветке 22 или Node.js 24+. Выполняйте команды из папки, где находится `package.json`.

```text
npm ci
npm run dev
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173). В Windows PowerShell можно использовать `npm.cmd` вместо `npm`.

```text
npm run typecheck
npm test
npm run build
npm run preview
```

Preview раздаёт готовую сборку из `dist` на [http://127.0.0.1:4173](http://127.0.0.1:4173).

## Проверка за пять минут

1. **Overview** — откройте просроченную задачу из очереди. Проверьте срок, ответственного и исходный запрос.
2. **New task** — добавьте ручной запрос. Проверьте, что карточка появилась в колонке New.
3. **Board** — попробуйте сохранить Ready for Production без брифа. Заполните бриф и отметьте три пункта, смените владельца и приоритет, затем сохраните.
4. **Task List / My Tasks** — найдите карточку, отсортируйте по сроку, переключитесь на нового владельца. Добавьте заметку и убедитесь, что она сохранилась после обновления браузера.
5. **Activity & Reminders** — поставьте открытой задаче вчерашний срок и откройте эскалацию с пометкой SIMULATION. В **Demo Guide** проверьте отмену и подтверждение Reset demo. На узком экране проверьте меню, горизонтальную прокрутку доски и таблицы, а также форму карточки.

## Устройство и данные

`src/model/config.ts` содержит статусы, команду и обязательные поля. `src/model/fixtures.ts` задаёт 30 примеров с датами относительно первого открытия или сброса. `src/model/workflow.ts` содержит переходы, историю, фильтры и правила риска. `src/model/storage.ts` валидирует снимок состояния из браузера. Интерфейс находится в `src/ui`, навигация и обновление состояния в `src/App.tsx`.

Для замены примеров отредактируйте массив `examples` в `fixtures.ts`. Используйте разрешённые обезличенные названия, описания, статусы, приоритеты, смещения дедлайнов и идентификаторы владельцев из `config.ts`. После обновления нажмите Reset demo, чтобы загрузить новые примеры в текущем браузере.

## Ограничения

Данные и настройки хранятся в localStorage текущего браузера и адреса приложения. Данные между устройствами и открытыми вкладками не синхронизируются. Черновик открытой формы не сохраняется. Напоминания и эскалации вычисляются из текущих задач и показываются только как симуляция. Для production-версии см. [PILOT_SCOPE.md](PILOT_SCOPE.md).

## Vercel

Публикация требует отдельного согласия. Для развёртывания подготовьте приватный репозиторий с приложением без материалов переговоров и свяжите его с проектом Vercel. Укажите каталог с `package.json`, пресет **Vite**, Node.js 24, команду `npm run build` и выходной каталог `dist`. Переменные окружения не требуются. После разрешённого развёртывания повторите сценарий из раздела проверки.
